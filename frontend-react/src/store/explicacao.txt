🧠 O que é a store

A store (ou armazenamento) é o centro de dados global da sua aplicação.
É onde ficam guardados todos os estados compartilhados entre telas e componentes, de forma centralizada.
Pense nela como uma “caixa” que guarda:
o estado global (dados do usuário, tema, carrinho, token, etc.)
e as regras para alterar esse estado (os reducers)

📦 Exemplo mental:

“A store é o cérebro da aplicação React/Redux — todos os componentes olham para ela quando precisam saber algum dado global.”

⚙️ E o que são reducers  

Um reducer é uma função que decide como o estado vai mudar quando uma ação acontece.

👉 O nome vem de “reduzir” — ele recebe o estado atual e uma ação, e devolve um novo estado.

Estrutura básica de um reducer:

const initialState = { count: 0 };

function counterReducer(state = initialState, action) {
  switch (action.type) {
    case 'INCREMENTAR':
      return { ...state, count: state.count + 1 };
    case 'DECREMENTAR':
      return { ...state, count: state.count - 1 };
    default:
      return state; // se não reconhecer a ação, mantém o estado
  }
}

🧩 Como tudo se conecta

Um projeto Redux normalmente tem essa estrutura:

store/
│
├── index.js        ← cria e exporta a store principal
├── reducers/
│   ├── userReducer.js
│   ├── cartReducer.js
│   └── index.js    ← combina todos os reducers

🔹 reducers/index.js

Esse arquivo junta todos os reducers individuais em um só:

import { combineReducers } from 'redux';
import userReducer from './userReducer';
import cartReducer from './cartReducer';

export default combineReducers({
  user: userReducer,
  cart: cartReducer
});

🔹 store/index.js

Aqui é onde a store Redux é criada e configurada:

import { createStore } from 'redux';
import rootReducer from './reducers';

const store = createStore(rootReducer);

export default store;


Depois, você envolve seu app com o Provider para permitir que qualquer componente acesse os dados:

import { Provider } from 'react-redux';
import store from './store';

export default function App() {
  return (
    <Provider store={store}>
      <MainRoutes />
    </Provider>
  );
}

🧭 Em resumo:
Termo	O que faz
store	Guarda o estado global da aplicação
reducer	Define como o estado muda (baseado nas ações)
action	Descreve o tipo de mudança que queremos fazer
dispatch	Envia a ação para o reducer executar
Provider	Conecta a store a todo o app
💬 Exemplo prático (visualizando o fluxo)

O usuário toca em “Adicionar ao carrinho”

O componente dispara (dispatch) uma ação:

dispatch({ type: 'ADD_PRODUCT', payload: product });


O reducer recebe a ação e atualiza o estado do carrinho.

A store armazena o novo estado.

Qualquer componente que lê o carrinho (via useSelector) é atualizado automaticamente.
